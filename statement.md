# Project Statement

## Problem Statement
Manual library management is time-consuming and can cause errors while tracking books, members and issue/return status. This project provides a simple Java-based solution for these operations.

## Scope
The system handles basic book/member records and issue-return transactions through a console interface. Data is maintained in memory during execution.

## Target Users
Students, small libraries and academic demonstrations.

## High-Level Features
- Book and member registration
- Record viewing
- Book issue and return
- Input validation and error handling
